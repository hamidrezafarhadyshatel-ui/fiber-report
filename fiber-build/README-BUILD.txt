FiberReport_Modular_v9.2 - ساخت APK بدون Android Studio

1) این پوشه را روی Windows کپی کنید.
2) روی build-apk.bat دوبار کلیک کنید.
3) اسکریپت خودش JDK 17، Android SDK و Gradle لازم را دانلود می‌کند.
4) در پایان فایل FiberReport_Modular_v9.2.apk در همین پوشه ساخته می‌شود.

نیازمندی‌ها:
- Windows 10/11 نسخه 64 بیتی
- اتصال اینترنت در اولین اجرا
- PowerShell (در Windows به صورت پیش‌فرض وجود دارد)
- حدود 1 GB فضای خالی برای ابزارهای Build

بعد از Build، برای نصب APK روی گوشی، فایل FiberReport_Modular_v9.2.apk را به گوشی منتقل و اجرا کنید.
